# fea/validation

Evidence that the finite element layer reads and solves what it claims (ADR-0029).

| Folder | Holds | Committed when |
| --- | --- | --- |
| `decks/` | Abaqus input decks used as fixtures: the team's model structure on small meshes | the material is from the public library and named in the deck's header comments |
| `cases/` | validation cases: a deck, expected numbers, a source, a tolerance (ADR-0007 style); format at the top of `src/anisotropy_fea/cases.py` | always |
| `abaqus/` (chunk 4) | comparison records: numbers the team exported from Abaqus, with provenance | the material is public |

The team's own decks, exports and any record that names a material not in the public library stay under `.local/fea/<tool>/<test>/` (ADR-0032) and are never committed (AGENTS.md). The local test `tests/test_local_tension_deck.py` reads them when present.

## Fixtures

- `coupon-1x1-im7-8552.inp`: one element, 10 mm by 80 mm, IM7/8552 [0/45/-45/45/0]s, 1 % axial strain by edge displacement, lateral edges free. The uniform-strain patch test of the next chunk.
- `coupon-2x8-grips-im7-8552.inp`: the team's model structure (parts, instance, assembly sets, node surfaces, kinematic couplings to two reference nodes, displacement-controlled step, PRESELECT output) on a 2 by 8 mesh with the same public material. Generated by a script in the chunk-1 pull request; edit by hand with care and keep the header comments true.
- `plate-1x1-isotropic.inp`: a homogeneous shell section with an isotropic material and a `Instance.label` boundary target. Nominal values, not a cited material.

- `coupon-2x2-im7-8552.inp`: the one-element coupon meshed 2 by 2. `coupon-1x1-cload-im7-8552.inp`: the same under 1000 N of edge load. `plate-1x1-isotropic-shear.inp`: the isotropic plate in simple shear.

## Cases

- `patch-1x1-im7-engine-equality`, `patch-2x2-im7-engine-equality`: prescribed 1 % axial strain, lateral edges free; expected strain, section force, reactions and displacements come from the engine's mixed solver on the same plies (recomputed live in `tests/test_membrane_solve.py`).
- `patch-1x1-cload-im7-engine-equality`: 1000 N edge load; expected values from the engine's forward solve.
- `isotropic-uniaxial-plane-stress`, `isotropic-simple-shear`: closed forms of isotropic plane stress (Timoshenko and Goodier, Chapter 2), by hand.
- The three IM7 cases also carry every ply's stress and strain in material axes (engine `ply_surfaces` on the same state) and the first-ply-failure factor by maximum stress, Tsai-Hill and Tsai-Wu (engine `first_ply_failure`, f* = 0 as the decks state). Only the factor is checked there: identical plies tie in a uniform state. The isotropic uniaxial case carries its one-ply stress, 700 MPa.

Fixture decks state the Tsai-Wu interaction term f* = 0 as the sixth `*Fail Stress` value, Abaqus's documented default made explicit (ADR-0021: the engine never assumes it).

Material numbers in the fixtures come from the library dataset `ncamp-im7-8552-2019-rtd-measured-v1` converted to MPa; `G13` and `G23` are nominal because Abaqus syntax requires them and this package does not use them.
