# fea/validation

Evidence that the finite element layer reads and solves what it claims (ADR-0029).

| Folder | Holds | Committed when |
| --- | --- | --- |
| `decks/` | Abaqus input decks used as fixtures: the team's model structure on small meshes | the material is from the public library and named in the deck's header comments |
| `cases/` (next chunk) | validation cases: a deck or inline mesh, expected numbers, a source, a tolerance (ADR-0007 style) | always |
| `abaqus/` (chunk 4) | comparison records: numbers the team exported from Abaqus, with provenance | the material is public |

The team's own decks, exports and any record that names a material not in the public library stay in `.local/abaqus/` and are never committed (AGENTS.md). The local test `tests/test_local_tension_deck.py` reads them when present.

## Fixtures

- `coupon-1x1-im7-8552.inp`: one element, 10 mm by 80 mm, IM7/8552 [0/45/-45/45/0]s, 1 % axial strain by edge displacement, lateral edges free. The uniform-strain patch test of the next chunk.
- `coupon-2x8-grips-im7-8552.inp`: the team's model structure (parts, instance, assembly sets, node surfaces, kinematic couplings to two reference nodes, displacement-controlled step, PRESELECT output) on a 2 by 8 mesh with the same public material. Generated by a script in the chunk-1 pull request; edit by hand with care and keep the header comments true.
- `plate-1x1-isotropic.inp`: a homogeneous shell section with an isotropic material and a `Instance.label` boundary target. Nominal values, not a cited material.

Material numbers in the fixtures come from the library dataset `ncamp-im7-8552-2019-rtd-measured-v1` converted to MPa; `G13` and `G23` are nominal because Abaqus syntax requires them and this package does not use them.
