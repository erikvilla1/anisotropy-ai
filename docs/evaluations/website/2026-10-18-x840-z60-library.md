# Evaluation: X840 / Z60 plain weave fabric enters the material library from a cited dissertation (ADR-0018, ADR-0020) | 2026-10-18

- Scope: `lib/curated-materials.ts` gains `chenX840PW` (material `x840-z60-pw`, dataset `chen-2015-x840-z60-pw-v1`): density, E1, E2, ν12, G12, G13, G23 from Table 3.1 and F1t, F1c, F2t, F2c, F12 from Table 3.2 of Z. M. Chen, *Experimental and Numerical Investigation of Wide Area Blunt Impact Damage to Composite Aircraft Structures*, PhD dissertation, UC San Diego, 2015 (printed p. 79, PDF p. 99). The source is registered for the monitor in `services/material-monitor/sources.ts`; the engine JSON is re-exported; the pinned counts move from 25 to 26 materials (`tests/curated-materials.test.ts`, `engine/tests/test_library.py`, `api/tests/test_library_api.py`).
- Why: the team's coupon decks use this material with exactly these constants (E1 = E2 = 80 000, ν12 = 0.06, G12 = 6 480, G13 = 5 100, G23 = 4 070 MPa). Until now its origin was not established, so every model that named it stayed under `.local/` (risk R-16). The founder supplied the dissertation on 2026-10-18.
- Rights class: `licensed-reference`. The title verso reads "Copyright Zhi Ming Chen, 2015, All rights reserved"; a public copy on eScholarship could not be confirmed from this machine (the site answered HTTP 202 to a direct fetch), so the recorded URL is the eScholarship search for the title, not a document link. Under this class the website shows the individual values with table and page and links no document, as for the textbook. The founder is to confirm the class; if the dissertation is found on eScholarship the class becomes `open-publisher` with the item link.
- The PDF copy stays in `References/2026-10-18/01-Thesis/` (git-ignored); its SHA-256 is recorded in the source. Verification: the two tables were read from the PDF text layer and checked against the rendered page.
- What the dissertation does not give: test methods or conditions (it states the values were provided by the material manufacturer, §3.2.1, printed p. 78), ply thickness, fiber volume, thermal expansion. A spec that uses this material must state the ply thickness (the team's decks use 0.1 mm). The tape row of the same tables and the fracture energies of Table 3.3 are not recorded.

## What this unlocks, and what still blocks it

- A finite element spec may now say `library = "x840-z60-pw"` with `ply_thickness = 0.1`, and the generated decks carry the citation in their header. First-ply failure by maximum stress and Tsai-Hill becomes possible for the team's layup (Tsai-Wu needs a stated f12*).
- Committing such a spec is still blocked by `fea/tests/test_spec.py` line 24, which accepts only `open-publisher` and `public-domain` materials in committed specs. That rule is stricter than the rights policy (ADR-0018 lets licensed-reference values appear publicly) and was written when no cited licensed material was wanted in a spec. Whether to widen it, or to wait for an `open-publisher` confirmation, is the founder's decision; the local X840-Z60 specs have been switched to the library material meanwhile.
