# Evaluation report 2026-10-02: laminate engine 0.1 verification

- Release tested: engine 0.1.0 at commit 2f3f5d5, merged to `main` as 615549d (pull requests #1 and #2)
- Test set: 148 automated tests, including 5 validation cases
- Method: engine output compared with printed textbook answers, closed-form textbook equations, independent calculations and physical laws. Deliberately planted bugs were used to confirm the tests detect errors.
- Scope: verification and textbook-level validation. No coupon test data yet.

## Weak spots found and what we did

- **Response:** a wrong curvature sign, or curvature left out, was caught only by the moment-equilibrium test. Added an independent beam-formula test; each bug is now caught twice.
- **Failure:** recording the wrong ply stress in the results was not caught, and swapping F1t and F1c was caught by only one test. Added tests for the stress at failure and for each basic strength; both bugs are now caught.
- **Laminate:** the magnitude of B is checked by one independent test, the [0/90] cross-ply B11. A brute-force numerical integration through the thickness would add a second check. Open.

## Source inconsistency recorded

Daniel and Ishai Table 7.3 prints Gxy = 38.2 GPa for the [+45/-45]s laminate, while its own 5.53 Msi equals 38.13 GPa. The engine gives 38.13 GPa; the validation case uses the Msi value.

## Limits of this evaluation

- No physical test data. Agreement with textbooks shows the code solves the equations correctly. It does not show the equations predict our coupons.
- Temperature and moisture effects are not modeled.
- Five validation cases so far; more answer-key sets are planned.

Approve for internal use: checking hand and homework calculations, and early design exploration. Not for design or certification decisions until predicted and measured coupon results have been compared.
