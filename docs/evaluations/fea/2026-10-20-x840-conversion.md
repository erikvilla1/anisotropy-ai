# Evaluation: the compression and open-hole models built the team's way, and a share folder of our models (ADR-0035, amendment 2) | 2026-10-20

- Scope: new specs `compression-coupon-x840-{coupling,nodal}` and `open-hole-coupon-x840-{coupling,nodal}`. They use X840-Z60 from the library (Chen 2015), [0/45/-45/45/0]s of 0.1 mm plies and the team's names. The coupling spec grips the whole tab through reference points; the nodal twin writes the same grips as constraints for CalculiX. Both keep their ASTM proportions. Their generated decks are added to the committed-deck tests, and each gets a CalculiX record and reading note. New script `docs/models/share.py` reads manifest `docs/models/our-models.toml`, and the material table writer moves into `team.write_material_csv`. The local IM7/8552 folders move under `.local/fea/<tool>/public-im7-8552/`. Usage examples, the validation README and the project-rules and workspace-layout skills are updated.
- Branch: `feat/x840-conversion`, stacked on `feat/deck-names` (PR #63).
- Environment: Windows 11, uv 0.13, Python 3.12, Gmsh 4.15.2, CalculiX 2.22 from the PrePoMax v2.6.0 bundle, Tectonic.

## What the numbers show

- Built the team's way, both coupons agree with CalculiX as the IM7/8552 ones did. The reactions differ by 0.19 % for compression and 0.06 % for the open hole, and every recorded strain and ply value is within the 3 % tolerance.
- Beside the hole the small components differ by up to 4 %, the same element-formulation difference the IM7/8552 record showed. It stays out of the record until the eight-node kernel element (chunk E).
