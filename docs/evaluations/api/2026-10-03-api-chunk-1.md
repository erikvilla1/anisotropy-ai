## What the API checks establish

- An axial single-ply request matches the independent compliance relation; an unsymmetric stack with mixed force/moment loads exactly matches direct engine calls for A/B/D, strains and curvatures.
- All six loads, units and a source reference are required. Explicit zero loads work. Unsupported units, unknown fields, invalid moduli/thicknesses, invalid compliance, numeric strings, booleans and non-finite values get HTTP 422.
- Extreme numerical inputs that overflow or produce singular stiffness return a client error. OpenAPI includes the required fields and structured response; `/docs` is served.
