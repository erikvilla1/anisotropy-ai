# Component card: laminate engine | version 0.1 | updated 2026-10-11

## Purpose and intended use

Compute every number in a laminate analysis from classical laminate theory, with inputs checked and results traceable to equations ([theory](../../engine/docs/theory.md)) and material sources ([library loader](../material-loader-2026-10-10.md)). Used from Python, from the case calculator, from the API and by the validation runner. Checks hand, homework and textbook answers; screens unnotched flat laminates.

## Out of scope / do not use for

Design allowables or certification (first-ply failure is the onset of cracking, not ultimate strength); holes, free edges, through-thickness stress, thick or sandwich plates, moisture, progressive failure, fatigue; plate buckling with clamped or free edges or of unsymmetric laminates.

## Inputs / outputs

In: a case (TOML, course Excel, JSON over the API, or Python objects): units; one material or several, typed or by library dataset id; the layup bottom-first with thicknesses; exactly one applied form (loads, average stress, strains, local stress or strain, forces with prescribed curvature, mixed conditions) with an optional temperature change; optional failure search loads, Tsai-Wu interaction term, strain-limit policy, plate size for buckling, and expected values.

Out: Q, S, Q̄, S̄; A, B, D and the inverse blocks; mid-plane strains and curvatures; loads given or solved; thermal resultants; ply strains and stresses on every face in both axis systems; engineering constants; strength ratios per face and first-ply failure by maximum stress, maximum strain, Tsai-Hill and Tsai-Wu with fixed and variable loads; plate buckling factor, loads and mode; and the comparison with expected values. SI inside, the case's units outside (ADR-0002). Invalid or half-filled input is refused with the field named (ADR-0003).

## Dependencies and versions

Python 3.12+, numpy, pydantic (`engine/uv.lock`); the material library export `data/material-library.json` (schema 1, regenerated by `npm run export:library`). No web or database code.

## Evaluation

408 unit tests and 32 validation cases, all passing at `1402c46`: [report of 11 October](../evaluations/2026-10-11-criteria-buckling-loader.md) and earlier reports in `evaluations/`. Validation sources: Daniel and Ishai (2006) problems and tables, course answer keys (numbers only), Whitney (1987) worked buckling results, constructed analytical checks.

## Known limitations

Ply-face checks only for interactive criteria; the Ritz buckling result is an upper bound that the user must converge by adding terms; strain limits derived from strengths assume linear behavior to failure and must be requested explicitly; no external buckling or maximum-strain answer key has been checked yet.

## Failure modes seen

- 2026-10-02: two unit-entry mistakes by hand (E1 as 2.13 for 21.3 Msi; 140e9 with psi units). The calculator's plausibility screen and explicit unit systems followed (ADR-0002).
- 2026-10-11: a founder's loads were read as N/m where the book meant N/mm; the engine was right and the cheat sheet now warns. The B matrix of a symmetric stack displayed roundoff; display fixed.
